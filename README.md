# 豆的一生 · Bean Garden

黑白手绘 SVG 风格的 AI 绿豆养成游戏，作为持久插件运行在 **DeepSeek Harness（DSH）** 中。主人在 DSH 侧栏照料豆子，朋友通过局域网页面串门聊天。

- 从小绿豆、生根、发芽、出叶、开花、结豆，到再次出芽、老化与生命终章。
- 结豆会诞生新豆，多颗豆子可以同时处于不同阶段、独立接受照料。
- DSH 当前默认模型生成性格、说话习惯、轮廓比例、眼睛、嘴巴及拟人对话。
- 所有游戏画面和图标使用 SVG，无 emoji；支持缩放、访客聊天记录及输入 IP 串门。
- 本地 JSON 保存生命参数、历史阶段、玩家动作和访客聊天。

## 安装（推荐：插件市场）

需要 DSH **0.2.1-rc.5 或兼容的更高版本**，并在 DSH 中配置可用的默认模型。

1. 打开 DSH 的「插件」页面。如果没有「发现」标签，在实验插件中启用 **自定义插件市场 / Custom plugin markets**。
2. 在「发现」中选择「添加索引源」，粘贴以下地址：

   ```text
   https://raw.githubusercontent.com/bulletyuan-agent/dsh-mung-bean-garden/main/index.json
   ```

3. 选择「豆的一生 / Bean Garden」，点击「安装」并确认来源。索引将版本固定到一个具体 Git 提交。
4. 安装完成后点击左侧栏的豆子图标。若 DSH 提示需要重启，按提示重启。

这是社区维护的公开插件索引，不是 DSH 官方内置源；DSH 默认不预置索引源。可以在安装确认页查看仓库与提交。

## 安装（让 DSH 中的 Agent 执行）

切换至支持插件管理的模式，然后把以下内容发送给 DSH：

```text
请安装这个 DSH 插件：
git+https://github.com/bulletyuan-agent/dsh-mung-bean-garden.git#v1.0.4
安装完成后启用「豆的一生」。
```

该方法无需 npm 发布账号。插件已提交构建产物，不要求运行 prepare/postinstall 等构建脚本。仓库为公开 GitHub 来源，需要能够访问 GitHub 和依赖 registry。

如果以前安装过本地 `@local/mung-bean-garden` 版本，请先禁用或移除旧插件，避免相同工具名和端口冲突；存档迁移见下文。

## 开始玩

- 初始愉悦为 0，先点「关注」5 次可以恢复完整摄入。
- 「浇水」投喂水 +1，「晒太阳」投喂能量 +1，「关注」愉悦 +2。
- 愉悦低于 10 时，水和能量的有效吸收量减半，豆子难过、生病并按天缩小。
- 每日水投喂超过 10，会呕吐、生病；每日能量投喂超过 20，会干枯、失水 10 并缩小。每种过量惩罚每天首次越过阈值时触发。
- 当前阶段的有效水与能量**合计严格超过 50**时进入下一阶段，两项阶段累计清零。生命参数和阶段累计分别保存。
- 两次结豆各产生一颗新豆；第二次结豆后第 2 / 3 / 4 天老化、枯萎、离世，按真实时间推进。
- 每日按 **Asia/Shanghai（UTC+8）零点**重置投喂计数和愉悦。
- 花园最多 48 颗豆（含老豆）。

## 局域网串门

插件启用时监听默认端口 **19816**，朋友在同一局域网打开：

```text
http://主人的局域网IP:19816/bean/
```

右上角「去看看其他豆」会验证 IPv4 并自动拼接默认端口和路径。朋友只需浏览器，无需安装 DSH，也不会获得模型 token。访客可以查看和聊天，不能照料；访客只能查看自己与所选豆的访客聊天，主人能查看所有访客与所选豆的对话。DSH 关闭或插件禁用后，访客服务停止。系统防火墙需要允许局域网设备访问该端口。

主人面板通过 DSH 自带的 Connection RPC 通道通信，支持桌面端 `dsh-app://app` 和 Web UI。UI 与 CSS 已打入 Client 工厂，没有从桌面源动态导入 HTTP 模块。

## AI 和消耗

复用 DSH 当前默认模型与认证，不要求在游戏里填写 API key。初生、阶段变化、对话和「唤醒 AI」会请求模型，消耗对应模型的额度或 token。模型不可用时明确标记临时角色状态，可重试；每次模型调用上限 60 秒。访客聊天每 IP 每分钟最多 10 次。照料动作即时反馈，稳定的阶段五官不会因为每次点击而重新随机。

## 存档与迁移

默认存档目录为：

```text
$DSH_PROFILE_DIR/data/mung-bean-garden/
```

无 profile 环境变量时回退至用户主目录下 `.dsh/data/mung-bean-garden/`。存档与插件安装目录分离，升级不会改动存档路径。三份文件：

| 文件 | 内容 |
| --- | --- |
| `growth.json` | 当前豆子、生命参数、阶段累计、每日摄入、历史阶段与 AI 形态/性格 |
| `actions.json` | 玩家动作记录 |
| `visitor-chats.json` | 访客标识、消息、回复与 AI 状态 |

每豆事件历史保留最近 500 条，动作及访客记录各保留最近 2000 条。三份文件使用相同 revision；损坏或不一致时会报错，不会自动覆盖重置。

迁移旧版本：先停用插件，把旧目录中三份 JSON **同时**复制到默认存档目录，再启用新版。不要合并不同 revision 的文件。可通过 DSH 的插件配置覆盖 `dataDir`，继续使用已有存档目录。修改端口时也需同步调整串门地址的默认拼接规则。

## 本地开发与验证

需要 Node.js 22 或更高版本：

```sh
npm install --ignore-scripts
npm run build
npm test
```

构建器生成版本化的 Host 与 Client 入口。DSH 桌面 UI 不需要额外前端构建器或 CDN；局域网页面使用本机提供的 Preact。

测试覆盖照料阈值、阶段进阶、繁殖、上海跨日、离线衰老、访客权限、AI 失败、存档恢复、RPC 错误/取消、资源自包含及发行包路径。MIT 许可；Preact 为其作者的 MIT 许可项目。

## 社区索引维护

`index.json` 使用 DSH 的 format 1 格式，来源指向本仓库固定提交。发布新版本时：更新 package.json 版本与 exports → 构建 → 测试 → 提交并打 tag → 更新索引中的版本和 commit。
